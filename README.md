# enliwfen

A javascript module intended to enliven web pages generated by server side driven web frameworks like [Django](https://www.djangoproject.com/). Such web pages are static in the sense that interaction with the server usually implies loading an entire page. Thinking in views as in Django leads to a limitation of a single view per page in the first place. Placing more than one view on a page and providing some actions like refreshing single views may lead to an unnecessary reload of all views.

That's where enliwfen comes into play. Currently more of a conceptual work, it aims to leave server side templates free of self written Javascript and free of apps like [Django Unicorn](https://www.django-unicorn.com/) bringing a toolset on top of and alongside of Django. To get it right, there is nothing wrong with apps like Django Unicorn. To the contrary, take a look at them, as they are powerful and may come with features better suited for your needs!

## Overview

enliwfen focuses on giving basic Javascript support addressed by attributes added to the elements in the templates rendered on the server side. In short:
* Form handling with Ajax-Calls
* Refreshing views with Ajax-Calls
* Ajax-Calls in general with document fragment responses
* Polling for updates
* Updates based on server side events
* Toggling attributes / classes
* Checkbox groups with a '(de-)select all' checkbox
* Dynamic data lists

A simple example:

~~~
<html>
<head>
...
<script type="importmap">
  {
    "imports": {
      "morphdom": "{% static 'morphdom/js/morphdom-esm.js' %}"
    }
  }
</script>
<script type="module" src="{% static 'enliwfen/js/enliwfen-esm.js' %}"></script>
...
</head>
<body>
...
<form id="my_form" class="enliwfen" method="post" action="/action">
</form>
...
</body>
</html>
~~~

~~~

~~~
